# Documentation module

The `docs/` directory describes how to run, understand, present, and extend
Annapurna AI.

| Document | Use it for |
| --- | --- |
| `SETUP.md` | Local and Docker setup, and every environment variable. |
| `API.md` | REST reference: authentication, the farm profile contract, and status codes. |
| `ARCHITECTURE.md` | Module map, data flow, scoring, and why ranking lives only on the server. |
| `TESTING.md` | Automated coverage and the manual acceptance checklist. |
| `DEFENSE_GUIDE.md` | Presentation script, design decisions, and honest limitations. |
| `ROADMAP.md` | Phases from prototype to production. |

At the repository root, `PROPOSAL_COVERAGE.md` maps every proposal objective to the
working implementation and states which data sources still need official credentials.
